# JobMatch Copilot Autofill extension

Fills employer apply forms from the user’s JobMatch profile (never auto-submits).

## Setup

1. Load the extension (Firefox temporary add-on or Chrome unpacked) from this folder
2. In JobMatch open **Apply Autofill** (`/extension/connect`) → **Connect Autofill**
3. Open an employer apply page → **JM** tab → **Autofill**

See the in-app page for browser-specific install steps.
